STADIUM ATLAS v1.18.0 — 10 MORE SCHOOLS
258 schools / 519 views. Existing state checkboxes and sorting are preserved.

UPLOAD IN THIS ORDER

1. Starting folder: your Stadium Atlas repository ROOT, where index.html lives.
   Open the existing assets folder. If you are already inside assets, stay there.
   Extract every image ZIP, then upload only the bare PNG files from each pack.
   All 20 new PNGs belong directly INSIDE assets. Do not upload ZIPs, a Part
   folder, or another assets folder. Do not delete existing images.

2. Return to repository ROOT. Open the existing scripts folder.
   Upload build_stadium_records.py from the extracted app ZIP's scripts folder,
   replacing the existing file. While INSIDE scripts, upload only that bare file.
   Its final path from ROOT must be scripts/build_stadium_records.py.

3. Return to repository ROOT. LAST, upload these FOUR app files together in
   one commit, replacing the existing files:
   index.html
   styles.css
   app.js
   catalog.js
   Do not upload this README, the code ZIP, its containing folder, or QA notes.

4. Open Actions and check the NEW workflow run for the final commit. If none
   starts, open Refresh Stadium Atlas records > Run workflow > main > Run workflow.
   Do not rerun an old job, which may use old files.
   A scheduled run between steps 2 and 3 can safely stop because the old catalog
   and new builder do not yet match; check a fresh run after step 3 instead.

5. After the new deployment succeeds, refresh the app with Ctrl+F5. The version
   badge should show v1.18.0, with 258 schools and 519 views.

Nothing else needs replacing. Keep existing assets, workflow, secrets,
site.webmanifest and domain settings. All existing 248 schools/499 views remain.

State choices still accept one or multiple states. All states clears just that
selection; Reset filters clears all browse filters. When any filter is active,
Start slideshow uses Current filtered results. All photos remains an explicit
slideshow choice. Every school's views stay together during shuffle.

Records: all 214 Division I schools are mandatory; 44 Division II/III schools
may explicitly show unavailable when a safe provider identity or valid record
cannot be verified. This update does not repair the previously unavailable
records. New authenticated provider validation is pending your live workflow;
offline tests do not establish live provider coverage.

Artwork is AI-generated, source-based illustration, not current photography or
survey-accurate depiction. Venue pages and source-era caveats are in the app.

The quiet bottom-center slideshow caption now also shows football division,
including the FBS/FCS distinction for Division I. This label comes from the
catalog, independently of whether the school's current records are available.
