UPLOAD IN THIS ORDER
1. START AT THE REPOSITORY ROOT (the page showing index.html).
   Open the existing assets folder. If you are already inside assets, stay
   there; do not open/create another assets folder. Extract every image ZIP
   on your computer and upload its PNG files directly into this open folder.
   Expected paths from the repository root are assets/<filename>.png.
   Keep all earlier images. Do not upload ZIPs or create Part folders.
2. RETURN TO THE REPOSITORY ROOT, then open the existing scripts folder.
   If you are already inside scripts, stay there. From the extracted app ZIP,
   select the file build_stadium_records.py inside its local scripts folder.
   Upload that FILE into the currently open GitHub scripts folder, replacing
   build_stadium_records.py. Final root-relative path:
   scripts/build_stadium_records.py — not scripts/scripts/...
3. RETURN TO THE REPOSITORY ROOT (not assets or scripts).
   LAST, replace these FOUR root files together in ONE commit:
   index.html
   styles.css
   app.js
   catalog.js
   Do not commit them individually or upload their containing local folder.
4. The index.html change triggers the existing records/deployment workflow.
   Open Actions > Refresh Stadium Atlas records and inspect the NEW commit.
   If needed, choose Run workflow on main. Do not re-run an old job.
5. After successful deployment, hard-refresh the site with Ctrl+F5.

Keep the existing workflow, secret, site.webmanifest, custom-domain settings
and all earlier assets. The notes/credits are reference documents, not extra
application files required for this upload. An automatic run between steps 2
and 3 may safely stop because the older catalog is still present; finish the
four-file commit and use its new run.

RECORDS
The latest fixes are included: safe missing-file diagnostics and explicit
record-inconsistent status. All 211 Division I schools remain mandatory.
The 37 Division II/III schools can show unavailable when no safe exact school
identity or record is found, or when verified numeric counts disagree.
No records are invented, normalized, or treated as zero. Malformed values,
wrong identities/seasons/classifications, duplicates and shared provider
errors remain blocking. Trinity Connecticut and University of New England
use conservative identities to avoid mixing up similarly named schools.
A later valid refresh automatically restores a withheld record.

Current authenticated provider coverage must pass your new workflow; no live
provider request or deployment was performed while preparing this update.
The original 233 schools and 469 view entries are retained unchanged.

ARTWORK

not current photographs or survey-accurate drawings. Fine markings, unseen
architecture and surrounding details are approximate. Source-era and factual
qualifications are disclosed in venue details and the included credits.
