4. Check Actions > Refresh Stadium Atlas records. Use the run for the NEW
   commit. If a manual refresh is needed, choose Run workflow on main;
   do not re-run jobs from an older commit.

Keep existing images, workflow files, CNAME/custom-domain settings, and other
repository files. README, credits, QA, source notes and manifests are reference
