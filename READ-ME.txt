STADIUM ATLAS v1.17.1 — PICK ONE OR MULTIPLE STATES

Starting folder: your Stadium Atlas repository ROOT, where index.html is listed.
Do not open assets or scripts for this update.

1. Extract this ZIP on your computer.
2. At the repository ROOT, choose Add file > Upload files.
3. Upload these FOUR extracted files together, replacing the existing files:
   index.html
   styles.css
   app.js
   catalog.js
4. Commit all four files together. Do not upload the ZIP, its containing folder,
   this READ-ME, or QA-NOTES.txt. No photo or records-script upload is needed.
5. In Actions, check the NEW workflow run for this commit. If no new run starts,
   open Refresh Stadium Atlas records > Run workflow > main > Run workflow.
   Do not rerun an old job: it can use the old files.
6. After the new deployment succeeds, open the app and press Ctrl+F5.
   The version badge should read v1.17.1.

HOW TO USE
Open States above the A–Z school buttons. Tick one or several state boxes.
A school may match ANY selected state; search, conference, division and school
letter choices still apply as additional filters. Counts beside states show
schools in the full collection, not counts under other active filters.
All states clears only the state selection. Unchecking the last state also
returns to All states. Selecting every state returns to All states as well.
Reset filters clears all browse filters. Sorting remains available separately.
Done or Escape closes the state choices. Selections stay while moving between
school details and the collection, but a page reload starts with All states.

Start slideshow now begins with Current filtered results whenever any browse
filter is active. Its Photos menu can still explicitly switch to All photos.
A filter with no matches stays empty; it does not silently show other states.

All 248 schools and 499 views remain. No image, record policy, provider mapping,
secret, or workflow changes are included. This does not fix unavailable records.
