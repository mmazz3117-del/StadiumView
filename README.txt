STADIUM ATLAS — 1.0

A fresh, standalone college-football stadium gallery.

OPEN OR UPLOAD
Open index.html in a current browser. No install or build is required.
For GitHub Pages, upload index.html, styles.css, app.js, catalog.js, and the
assets folder to your Pages repository. Keep that folder structure intact.
This is a separate app. It does not modify Comic Vault.

WHAT IS INCLUDED
- Search by school, stadium, team, or city.
- School A–Z board, All, clear search, and reset filters.
- One completed entry: Oregon / Autzen Stadium, with two aerial views.
- Full-screen image viewer, scroll or pinch zoom, drag pan, and fit reset.
- Keyboard support: Escape closes the viewer; + / - zoom, 0 fits the image,
  and arrow keys pan when the image area is focused.
- Browser Back closes the image viewer and returns to the collection.
- Responsive phone, tablet, desktop, and landscape layouts.

IMAGES
The two supplied, approved PNGs are included without resizing, recompression,
or compositional changes. Each is 1672 × 941 pixels. Fit preserves the whole
image. Zoom stops at its native dimensions; it cannot create extra detail.
These are AI-generated, reference-based 2024-era reconstructions, not current
photographs. The app displays this distinction in the stadium detail view.

STADIUM INFORMATION
University of Oregon Athletics:
https://goducks.com/facilities/autzen-stadium/22

ADDING STADIUMS
Only Oregon is built in this version. Other letters intentionally show an
honest empty state. New entries need approved images and a matching detail
view; catalog.js is the starting point for future batches.

TECHNICAL
Static HTML, CSS, and JavaScript. No account, backend, tracking, external
scripts, external fonts, or package dependencies. Relative paths work on
GitHub Pages subpaths. Viewer routes use URL fragments.
